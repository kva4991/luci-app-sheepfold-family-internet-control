# Исправления восстановления и чтения состояния: r288

Дата: **08.09.2026**. База: `ed8e335fdd52286190e1f6ec067cd634e8b1ce94` (r287).
Версия пакета: `0.1.0-288`. Это локальный интеграционный снимок, не stable-релиз.
В GitHub изменения не отправлены, исходные ветки и их история не удалены.

## Изменения

В [подробном накопительном реестре](bug-register.ru.md) находятся 21 карточка дефектов,
решение владельца D01 и отдельно неподтверждённые риски. B01–B13 исправлены в r287;
новые изменения этого прохода — B14–B21:

| ID | Изменение | Почему |
| --- | --- | --- |
| B14 | Маркер поколения runtime проверяется рядом с RAM-хэшем и записывается атомарно с правилами | Имена объектов не доказывают сохранность содержимого после их пересоздания |
| B15 | Clear существующих собственных объектов выполняется одним nft batch | Ошибка не должна оставить половину ограничений снятыми |
| B16 | Сохраняется будущая граница ещё не активного расписания | `none` сейчас не означает отсутствия известного следующего события |
| B17 | Повтор device-allow подтверждает sync даже при уже сохранённом allow | Commit намерения не доказывает успешное применение |
| B18 | CLI отдельно проверяет десятичные минуты до UCI-записи | Другие клиенты обходят API; `0010` не должно означать восемь |
| B19 | Нечитаемый UCI останавливает расчёт до nft и даёт неизвестный статус | Ошибка чтения не равна пустой разрешающей конфигурации |
| B20 | Сбой list-devices даёт 503 вместо ложной пустой семьи | Пустые данные и недоступные данные — разные результаты |
| B21 | Все строковые поля device JSON экранируются | Допустимый текст не должен повреждать структуру ответа |

Приоритет «Без ограничений» выше чёрного списка устройств для обычного интернета
сохранён. Management deny и карантин остаются независимыми. Новых удалённых функций,
изменений strict-site bootstrap или автоматического отключения flow offloading нет.

Штатный fw4 include уже вызывал принудительное восстановление. B14 укрепляет резервный
periodic sync, когда штатный путь не восстановил runtime; не утверждается, что каждый
обычный reload прежде терял все sets. Marker размещён в цепочке, поскольку `flush table`
сбрасывает правила цепочек, но не очищает sets. Он не подключён к packet hook.

## Локальные проверки

Полный `SHEEPFOLD_TEST_BATCH_SIZE=16 npm test` завершён: **922/922**, 130 файлов,
ошибок, пропусков и отменённых тестов нет. Добавлено 34 сценария в двух новых файлах,
оба включены в `tests/categories.mjs`. Старые тесты ownership/ID исполняют новый serializer
вместе с реальной функцией списка; проверки владельца и постоянства ID не отменены.

`python scripts/build-test-ipk.py --variant all` собрал Standard и AI Support:

```text

.build/ipk-output/luci-app-sheepfold-ai-support_0.1.0-288_all.ipk
```

Это локальная проверка упаковки, не официальный SDK. Makefile и postinst задают
`ui_asset_version` из версии пакета; исходный sentinel `0.0.0-0` в defaults не является
номером установленного релиза и не заменяется вручную. AI-only библиотека JSON не
добавлена в Standard. Новая сериализация использует уже имеющийся awk.

Дополнительно проверены 99 shell-файлов (BusyBox ash/Bash), синтаксис 7 изменённых
JavaScript-модулей, 254 Markdown-файла и актуальность каталога значков. Содержимое двух
готовых IPK сверено с общими helpers и nft-фрагментом; проверены права исполняемых
файлов, postinst, версия UI и изоляция AI. 12 соседних тестов документации/категорий/
готовых пакетов прошли отдельно после обновления документов.

Структурный анализ сохраняет предупреждение по legacy CLI: 2221 строка при ориентире
900. Это не скрытая ошибка теста; декомпозиция остаётся техническим долгом R07.
Полный ESLint не запущен: executable отсутствует, установка npm-зависимостей не
завершилась, offline-попытка дала ENOTCACHED. Оба Android Wrapper остановились до задач
из-за `UnknownHostException: services.gradle.org`. Эти проверки не считаются пройденными.

Точные дополнительные журналы, ограниченные проверки и финальный Git hash находятся
в сопровождающем внешнем отчёте. Наличие команды не означает, что отсутствующий
инструмент успешно выполнился. Документация и тесты не содержат реальных семейных данных.

## Не подтверждено

Нет нового живого OpenWrt/телефона, настоящего `nft --check`, packet/DNS/offload-проверок,
официального SDK/CI именно этого снимка, аппаратного PowerShell rollback. Маркер не
обнаруживает любое точечное чужое изменение набора. Проверка UCI в начале не является
общим snapshot всех getters. Точность времени отключения всё ещё требует успешного sync.
Полный JavaScript ESLint и Android Gradle/SDK требуют доступных зависимостей и отдельно
учитываются во внешнем отчёте. Изолированный Kotlin-тест в Node suite не заменяет APK.

## Повтор проверки

Рабочий каталог — корень репозитория. Node, POSIX shell/awk/sed, BusyBox при наличии,
Python 3, Java/kotlinc для Kotlin-regression; loopback разрешён для полного suite.

production shell на рабочем компьютере с правами root. Отказ среды, loopback или
загрузки зависимости сохраняется как ограничение, а не маскируется пропуском теста.
