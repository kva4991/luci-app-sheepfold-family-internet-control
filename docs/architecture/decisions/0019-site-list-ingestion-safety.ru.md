# ADR-0019: безопасная загрузка и последняя рабочая копия списков сайтов

- Статус: Принято
- Дата: 2026-08-08
- Теги: `§slstres`, `§dompol`
- Связанные документы: [Источники списков сайтов](../../site-list-sources.ru.md), [Доменная политика](../../site-domain-policy.ru.md)

## Контекст

Внешний источник может вернуть HTML ошибки вместо списка, оборванный файл,
неожиданно малую выборку или чрезмерный объём. Обычный HTTP допускает незаметную
подмену по дороге. Одновременно домашний роутер имеет ограниченные RAM, flash и CPU,
поэтому без верхних границ даже корректный список может нарушить маршрутизацию.

## Рассмотренные варианты

1. Принимать любой успешно скачанный файл. Отклонено: транспортный успех не доказывает корректность содержимого.
2. Удалять устаревший кэш после фиксированного срока. Отклонено: временный сбой поставщика не должен сам выключать уже работавшую защиту.
3. Разрешить внешний HTTP после предупреждения. Отклонено для 1.0: предупреждение не обеспечивает целостность списка.
4. Проверять каждый источник отдельно, ограничивать ресурсы и атомарно заменять только подтверждённую рабочую копию. Выбрано.

## Решение

- Внешние URL принимаются только по HTTPS. `http://127.0.0.1` разрешён как узкое исключение для локального генератора на самом роутере; userinfo, перенаправление в недоверенный transport и произвольный внешний HTTP запрещены.
- До живых измерений Xiaomi AX3000T является контрольным ресурсным стендом. Один источник ограничен `250 000` строками доменов, итог — `500 000` уникальных доменов; действуют также лимиты размера скачанного и распакованного файла.
- Плохие строки отбрасываются отдельно. Полностью плохой файл не заменяет рабочую копию.
- Если прежняя копия содержала не меньше `1000` доменов, а новая потеряла более `75%`, замена требует отдельного подтверждения владельца.
- Последняя рабочая копия применяется без срока давности до успешной замены или явного удаления источника. Её возраст и причина неудачного обновления видны владельцу.
- Ошибка одного источника не останавливает остальные; повтор выполняется через сутки, а после трёх неудачных циклов создаётся административное уведомление.

## Последствия

- Фраза «поддерживает 500 000 доменов» остаётся защитной границей, а не обещанием производительности до живого теста AX3000T.
- Более слабому роутеру можно выбрать меньшие источники, AdGuard Home или вынесенный пользовательский обработчик.
- Старый список может содержать устаревшие записи, но это явно показывается и считается безопаснее незаметного отключения защиты.
- Защита транспорта и нормализация списка не закрывают обход через DoH/DoT, VPN, proxy или прямой IP; это отдельное известное ограничение 1.0.

## Проверка

`siteListResilience.test.mjs`, проверка shell-синтаксиса и живой прогон большого источника на Xiaomi AX3000T с замером RAM, CPU, flash и времени применения.

## Когда пересматривать

После накопления живой статистики AX3000T, появления подписанных источников либо реализации потоковой обработки с доказанными меньшими затратами памяти.
