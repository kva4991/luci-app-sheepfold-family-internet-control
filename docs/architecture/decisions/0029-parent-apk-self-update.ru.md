# ADR-0029: Ручное обновление родительского APK

- Статус: Принято
- Дата: 2026-08-31
- Теги: `§apkupd1`
- Текущий контракт: [обновление Android](../../android-app-updates.ru.md).
- Продолжение установки и восстановление после Settings дополнены [ADR-0030](0030-resumable-parent-apk-installation.ru.md).

## Контекст

Родителю нужна отдельная кнопка обновления приложения, распространяемого вне магазина.
Он не должен искать файл среди OpenWrt-пакетов и детских APK. Маломощный роутер не должен
проксировать десятки мегабайт или определять доверенный Android-ключ.

## Решение

Ручная проверка в «Информации», ограниченный HTTPS download из публичных релизов одного
репозитория GitHub. Канал отделён от router-data refresh и временной поддержки.
Нет фоновой установки, пользовательских URL, root-доступа и новых Gradle-зависимостей.
APK должен иметь ту же подпись, тот же package ID и строго большую версию.
Установку подтверждает человек в системном Android installer.

## Рассмотренные варианты

- Ручная загрузка из фиксированного GitHub-канала с системной установкой: выбрана.
- Установка при входе или из WorkManager: не соответствует явной кнопке.
- Произвольный APK URL из ответа роутера: расширяет доверие до удалённого кода.
- Только checksum/имя: не доказывают, кто подписал приложение.
- Удаление приложения ради другого сертификата: теряет настройки и защиту.
- Новая облачная служба только ради APK: пока не нужна, используется существующий GitHub.

## Последствия

Без корректно опубликованного APK кнопка сообщает его отсутствие. Production-ключ не
заменяется debug-ключом; ротация требует отдельного решения. Публикация релизов,
Google Play distribution и обновление детского APK не считаются реализованными этим
изменением. Runbook и пределы доказательства находятся в профильном документе.

## Проверка

JVM-тесты проверяют выбор релиза, ограничения загрузки, подпись, версию и отмену.
Инструментальные тесты проверяют состояния кнопки, повторные нажатия и поворот экрана.
Команды, результаты и ещё не проверенный production-переход описаны в
[инструкции проверки обновлений](../../android-app-updates.ru.md).

## Когда пересматривать

При публикации через магазин, ротации Android-ключа, изменении GitHub-канала
или расширении обновления на детский APK. Новый канал не должен обходить
проверку подписи или требовать удаления установленного приложения.
