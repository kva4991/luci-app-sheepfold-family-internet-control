# Каталог значков Sheepfold

<!-- §iconcat1 -->

Каталог хранит **собственные интерфейсные значки Sheepfold** и показывает, где используется каждый из них. У каждого значка есть одно уникальное английское имя в `camelCase`.

Открыть все значки разом: [`catalog.html`](catalog.html).

## Источник истины

- `catalog.json` — имена, SVG-геометрия, назначение и места использования;
- `scripts/generateIconCatalog.mjs` — проверяемый генератор;
- `shared/icon-registry.js`, `catalog.html` и собственные Android `ic_*.xml` — генерируемые файлы, их вручную не редактируют;
- `docs/assets/sheepfold-*.png` — исходники фирменной растровой графики.

После правки `catalog.json`:

```powershell
npm run icons:generate
npm run icons:check
node --test tests/iconCatalog.test.mjs
```

Если забыть генерацию, тест завершится ошибкой и назовёт устаревший файл. Поэтому изменение SVG в каталоге не может незаметно остаться только на странице-превью или только в одном экране LuCI.

## Правила

1. Имя описывает смысл, а не внешний вид: `actionSettings`, а не `smallGear`.
2. Одно действие во всех окнах использует одно имя.
3. SVG-пути нельзя писать внутри feature/view-файлов. Новый значок сначала добавляют в `catalog.json`.
4. Цвет состояния задаётся CSS в месте использования; отдельные имена нужны, когда различается смысл состояния.
5. Внешние системные значки Android можно оставить системными. Каталог управляет собственной графикой Sheepfold, а не копирует всю Material Icons.
6. У каждого значка заполняется список реальных мест использования. Неиспользуемый значок удаляют либо явно обосновывают.
7. Основной силуэт и внешние линии хранятся в `paths`. Более тонкие внутренние детали можно вынести в `thinPaths`: генератор одинаково применит к ним уменьшенную толщину в LuCI, HTML-каталоге и Android Vector Drawable.
8. `network`, `router` и `network_switch` — разные типы и разные значки. Не заменять их одним универсальным изображением при изменении классификатора.

Фирменный Android launcher содержит созданные Android Image Asset density-варианты. В каталоге хранится и показывается их исходник `sheepfoldAppIcon`; сами raster-варианты обновляются отдельно через Android Studio, потому что простое уменьшение PNG ломает adaptive-icon safe zone.

Архитектурное объяснение и границы каталога: [`docs/icon-catalog.ru.md`](../docs/icon-catalog.ru.md), ADR-0017.
