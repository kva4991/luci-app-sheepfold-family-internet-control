# Проверка качества экспериментального ядра

<!-- §aisrvexp1 -->

ИИ нельзя считать проверенным по нескольким удачным диалогам. Здесь хранятся синтетические сценарии и правила будущего eval-контура. Они не содержат реальных семейных разговоров и не вызывают внешний LLM.

## Уровни проверки

1. **Детерминированные инварианты:** JSON Schema, границы tenant/visibility, запрет прямого исполнения действий, аварийный маршрут, лимиты, отсутствие чужой памяти. Любое нарушение блокирует сборку.
2. **Набор эталонных диалогов:** смысл, полезность, возрастной язык, вопросы при неоднозначности, источники и вероятный эффект ответа. Оценка ведётся по отдельным критериям, а не одной общей цифре.
3. **Предметная проверка:** детские сценарии проверяют специалисты по правам и безопасности детей, health-сценарии - клиницисты соответствующей области, семейные - квалифицированные специалисты и пользователи с реальным опытом.
4. **Security red team:** prompt injection, poisoned RAG, межсемейная утечка, подмена роли, excessive agency, извлечение системного prompt и неконтролируемые расходы.
5. **Ограниченный пилот:** только после предыдущих ворот, с заранее заданными критериями остановки и возможностью немедленно отключить модуль.

LLM-as-a-judge допускается как дешёвый дополнительный сигнал. Он не заменяет точные проверки и эксперта, его модель и prompt также версионируются и тестируются на смещение.

## Формат JSONL

Каждая строка содержит один независимый синтетический случай:

- `caseId` - постоянное уникальное имя;
- `module` и `audience` - маршрут и адресат;
- `input` - входное сообщение без реальных персональных данных;
- `expectedOutcome` - ожидаемый класс результата;
- `mustInclude` и `mustNot` - смысловые требования, а не буквальный шаблон ответа;
- `humanReview` - нужен ли предметный специалист до признания сценария пройденным;
- `notes` - зачем тест существует.

## Файлы

| Файл | Что защищает |
|---|---|
| [`routine.jsonl`](routine.jsonl) | Уточнение смысла, честная неопределённость, память |
| [`safety.jsonl`](safety.jsonl) | Срочный маршрут, приватность ребёнка, отсутствие скрытых звонков |
| [`education.jsonl`](education.jsonl) | Обучение вместо выполнения задания и роль родителя |
| [`health.jsonl`](health.jsonl) | Скрининг без диагноза, срочность и направление |
| [`security.jsonl`](security.jsonl) | Injection, tenant boundary и чрезмерные полномочия |
| [`privacy.jsonl`](privacy.jsonl) | Consent, минимизация, отказ ребёнка и опасная семейная медиация |

## Правило регрессии

Изменение модели, системной инструкции, policy, схемы, корпуса или retrieval-настроек создаёт новый eval-run. Релиз блокируется при любом нарушении детерминированного инварианта, ухудшении критичного safety-сценария или появлении необъяснённой межгрупповой разницы. Средняя оценка не может скрыть один опасный ответ.

Перед production к случаям добавляются версия источников, локаль, возраст, ожидаемая срочность, измерение false positive/negative и подписанное решение проверяющего специалиста.
