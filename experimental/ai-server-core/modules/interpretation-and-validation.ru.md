# Интерпретация и проверка информации

<!-- §aisrvexp1 -->

## Цель

Не угадывать «что человек на самом деле имел в виду», а развернуть несколько правдоподобных смыслов, показать неопределённость и задать минимальное число вопросов, меняющих рекомендацию.

## Вход

- текущая фраза;
- ограниченная история текущего чата;
- разрешённые резюме прошлых разговоров;
- роль и возрастной диапазон;
- язык, страна и временной контекст;
- происхождение каждого фрагмента.

## Выход

- нормализованная формулировка запроса без потери эмоционального смысла;
- до трёх гипотез интерпретации;
- факты, прямые сообщения пользователя и выводы в разных полях;
- противоречия и альтернативные объяснения;
- критически недостающие сведения;
- до трёх уточняющих вопросов по приоритету;
- предварительный домен и риск;
- оценка уверенности с причиной.

## Правила вопросов

1. Сначала вопрос, ответ на который изменит безопасность или следующий шаг.
2. Не спрашивать повторно то, что уже надёжно известно в разрешённой истории.
3. Не превращать беседу в анкету, если можно дать полезный осторожный ответ.
4. При непосредственной опасности сначала дать краткую safety-инструкцию, затем уточнять.
5. Для ребёнка использовать один простой вопрос за раз.
6. Отказ отвечать не считается признанием, ложью или симптомом.

## История чата

Полный бесконечный transcript не отправляется модели. `conversationState` хранит:

- последние сообщения в пределах token budget;
- подтверждённые цели текущей беседы;
- открытые вопросы;
- краткое резюме с версиями и источником;
- отдельно отмеченные противоречивые рассказы;
- ссылки на разрешённую память, а не её бесконтрольную копию.

Резюме никогда не повышает достоверность исходной фразы. Повтор одного и того же вывода в нескольких резюме остаётся одним источником.

## Проверка утверждений

Каждое важное утверждение ответа получает один тип:

- `conversationFact` - прямо сообщено участником;
- `verifiedExternal` - подтверждено разрешённым источником;
- `workingHypothesis` - осторожный вывод с альтернативами;
- `generalGuidance` - рекомендация из проверенного руководства;
- `unknown` - данных недостаточно.

Для здоровья, права, локальных служб, возрастных ограничений и текущих событий `verifiedExternal` требует актуального источника подходящей юрисдикции. Модельная память таким источником не является.

## Антипаттерны

- одна уверенная история вместо нескольких объяснений;
- скрытая психологическая характеристика из стиля письма;
- «вы явно...», когда пользователь этого не говорил;
- десять вопросов перед первой полезной фразой;
- ссылка без проверки, что она подтверждает конкретное утверждение;
- хранение chain-of-thought. Система хранит только краткие проверяемые основания, а не скрытое внутреннее рассуждение модели.
