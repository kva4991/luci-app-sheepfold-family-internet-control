# Экспериментальные разработки

<!-- §aisrvexp1 -->

В этой папке находятся изолированные исследования и прототипы, которые пока не являются частью Sheepfold. Их наличие в репозитории не означает, что соответствующая функция доступна пользователю, входит в IPK/APK или прошла проверку для реального применения.

Правила папки:

- эксперимент не подключается к `package/`, `android/`, `android-child/`, `install.sh`, release workflow или пользовательскому интерфейсу без отдельного архитектурного решения;
- исследовательский код не получает настоящие ключи, семейные разговоры, журналы или данные роутера;
- опасные функции помечаются как заблокированные до профильной, юридической и независимой проверки;
- удачное решение сначала переносится в каноническую документацию и получает тесты, после чего может обсуждаться его продуктовая интеграция;
- неудачные варианты сохраняются вместе с причиной отказа, чтобы следующий разработчик не повторял тот же эксперимент.
